What a sentence would look up

This is not the conversation layer. It reads a sentence, goes and fetches what that sentence points at, and shows both — but it writes no reply. Assembling the fetched records into a briefing is still to be built, so a reply here would be a mock-up rather than the thing itself.

Everything this layer decides is invisible by design: it happens between somebody speaking and the assistant answering, and never reaches a screen. That is right for the product and unworkable for anybody trying to tell whether the reading is any good. So there is one way in.
